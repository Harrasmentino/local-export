# Фиксированные отчёты без ИИ

[К основной инструкции](../README.md)

Этот режим получает свежие страницы Confluence из `links.txt` и создаёт два Excel и два Word на компьютере. Он ищет разделы по заголовкам и ключевым словам, переносит исходные формулировки и ссылки. ИИ в обработке не участвует.

Произвольные темы и выборки доступны в [режиме агента](../README.md). Здесь набор отчётов задан программой.

## Что понадобится

- Скачанная папка проекта и доступ к нужным статьям Confluence Cloud.
- Email Atlassian и API-токен без scopes, если такой токен разрешён организацией. [Как получить токен](../README.md#api-токен).
- Windows или macOS, Python 3.12+ с `python-docx`, Node.js и пакет `@oai/artifact-tool`.

`VYGRUZKA.bat` на Windows и `VYGRUZKA.sh` на Mac рассчитаны на уже подготовленный набор библиотек Codex. Репозиторий не содержит и не устанавливает эти зависимости. Подробности — в [настройке окружения](#окружение-и-параметры).

## 1. Собери ссылки на статьи

Скопируй [links.example.txt](../links.example.txt) в папке проекта под именем **`links.txt`**. Открой копию в Блокноте и удали вымышленную ссылку из примера.

Для каждой нужной авиакомпании открой саму опубликованную статью в Confluence, дождись загрузки и нажми **Ctrl+L → Ctrl+C**. Вставь адрес в `links.txt`: одна ссылка на строку, без кавычек, нумерации и названия компании.

Пример — адреса вымышленные:

```text
https://your-company.atlassian.net/wiki/spaces/AIR/pages/123456789/Airline-One
https://your-company.atlassian.net/wiki/spaces/AIR/pages/987654321/Airline-Two
```

Поддерживаются полные HTTPS-ссылки с числовым ID после `/pages/` или в параметре `pageId`:

```text
https://your-company.atlassian.net/wiki/pages/viewpage.action?pageId=123456789
```

Все статьи должны быть на одном сервере. Короткую `/x/…` сначала открой в браузере и скопируй конечный полный адрес. Ссылка на базу, пространство, поиск или родительский раздел не заменяет список: этот режим не обходит дочерние страницы.

Сохрани файл в UTF-8 рядом с запускниками. Проверь имя: **`links.txt`**, не `links.txt.txt`. При необходимости включи отображение расширений в Проводнике. Публичный доступ к статьям включать не нужно. Не отправляй рабочий список в чат или Git.

## 2. Запусти выгрузку

1. На Windows открой **`VYGRUZKA.bat`**. На Mac открой Terminal в папке проекта и выполни `sh ./VYGRUZKA.sh`.
2. При первом подключении введи email и токен в открывшейся **локальной консоли**. Символы токена не отображаются — это нормально. Это не отдельная форма режима агента.
3. Дождись сообщения **«Сформировано: 2 Excel и 2 Word»**.
4. Скопируй путь после **«Результаты:»** в адресную строку Проводника и открой нужный файл.

| Файл | Что внутри |
| --- | --- |
| `aviakompanii_svodka.xlsx` | Общая сводка правил, войды, штрафы при обмене, штрафы выше тарифа и неявка |
| `neyavka.xlsx` | Таблица по неявке и распределение авиакомпаний по категориям |
| `neyavka_tablica.docx` | Краткая таблица по неявке |
| `neyavka_spravochnik.docx` | Подробный справочник по неявке с формулировками и ссылками |

Результаты по умолчанию находятся в отдельной папке каждого запуска внутри:

- Windows: `%LOCALAPPDATA%\ConfluenceLocalExport\exports`
- macOS: `~/Library/Application Support/ConfluenceLocalExport/exports`

Рядом с отчётами лежат полученные страницы в `source_snapshot.json`, данные для отчётов в `report_data.json` и сведения о сборке в `report_info.json`.

**Если есть `INCOMPLETE.txt`, выгрузка не завершена.** Даже появившиеся Excel и Word нельзя считать готовыми. Устрани ошибку и запусти программу ещё раз.

## Обновление данных и доступов

Для новой таблицы снова запусти `VYGRUZKA.bat` на Windows или `sh ./VYGRUZKA.sh` на Mac. Все страницы из списка скачиваются заново; открытый Excel сам не обновляется. Чтобы включить новую карточку, добавь её ссылку в `links.txt`. При ошибке загрузки хотя бы одной страницы готовые отчёты не формируются, старый снимок вместо свежего не используется.

После первой успешной загрузки email и токен сохраняются в Windows Credential Manager или macOS Keychain. При следующих запусках вводить их не нужно. Оба режима программы используют одну запись доступов для одного сервера Confluence.

При **401** консоль один раз запросит новые доступы и перезапустит всю загрузку. Email можно оставить прежним, нажав Enter; пустой токен отменяет запуск. При повторном отказе программа останавливается, при **403** автоматической замены нет. Новые доступы сохраняются только после успешной загрузки всех страниц.

Для ручной замены выполни в PowerShell из папки проекта:

```powershell
.\VYGRUZKA.bat --update-credentials
```

```bash
sh ./VYGRUZKA.sh --update-credentials
```

Программа не продлевает срок токена. Правила хранения и удаления доступов описаны в [основной инструкции](../README.md#что-остаётся-локально-а-что-получает-ии).

## Как читать отчёты

- «Не найдено» не означает, что правила нет: статья может быть оформлена иначе.
- Количество минут до неявки определяется только для простой явной формулировки. Разные сроки, условия и исключения требуют проверки.
- По штрафам и таксам показываются исходные фрагменты. Программа не превращает неоднозначные условия в безусловное правило.
- Краткие листы могут содержать выдержки. Полные найденные фрагменты — на листе **«Исходные фрагменты»**, исходные страницы — в `source_snapshot.json`.
- Длинные фрагменты разбиваются на части. Содержимое высокой ячейки можно читать в строке формул Excel.
- Вложения, внешние сайты и страницы вне списка отдельно не скачиваются. Автоматическое извлечение не заменяет экспертную проверку правил.

## Окружение и параметры

Windows-запускник по умолчанию ожидает библиотеки в каталоге:

```text
%USERPROFILE%\.cache\codex-runtimes\codex-primary-runtime\dependencies
```

Внутри нужны `python\python.exe` с `python-docx`, `node\bin\node.exe` и `@oai/artifact-tool` в `node\node_modules`. Открывать Codex для выгрузки не требуется — используются файлы на диске. Без этих зависимостей скачанного ZIP недостаточно.

На Mac VYGRUZKA.sh сначала проверяет локальный набор Codex, затем python3 и
ode из PATH. Путь к модулю можно указать через LOCAL_EXPORT_MODULES. Скрипт ничего не устанавливает автоматически.

Запускник создаёт `_local/node_modules` как ссылку на каталог библиотек (`junction` на Windows, симлинк на Mac). Не копируй её содержимое при переносе программы. Для отдельного Python используй `python -X utf8 local_export.py` из папки проекта; Node.js, пакеты и ссылка `_local\node_modules` должны быть подготовлены заранее.

| Задача | Windows PowerShell | macOS shell |
| --- | --- | --- |
| Другой список страниц | `.\VYGRUZKA.bat --links "D:\PrivateExports\links.txt"` | `sh ./VYGRUZKA.sh --links "$HOME/PrivateExports/links.txt"` |
| Другая папка результатов | `.\VYGRUZKA.bat --output-dir "D:\PrivateExports"` | `sh ./VYGRUZKA.sh --output-dir "$HOME/PrivateExports"` |
| Сравнить с прошлой выгрузкой | `.\VYGRUZKA.bat --previous "D:\PrivateExports\previous-run\source_snapshot.json"` | `sh ./VYGRUZKA.sh --previous "$HOME/PrivateExports/previous-run/source_snapshot.json"` |

Сравнение добавляет лист **«Что изменилось»** в общую сводку. Прошлый снимок используется только для сравнения, текущие страницы всё равно скачиваются заново.

`local_export.py` извлекает правила и управляет сборкой, `local_documents.py` формирует Word, `_local/export_xlsx.mjs` — Excel. После скачивания сеть блокируется в процессах обработки: Python-защитой и `_local/network_off.mjs`. Вызовов ИИ и отправки данных разработчику нет.

## Если выгрузка остановилась

При `Required local runtime or libraries are missing` проверь окружение выше. До подключения проверь наличие `links.txt`, его кодировку, полные ссылки на один сервер и права на папку результатов. При ошибке скрытого ввода запусти `.bat` самостоятельно в обычной локальной консоли.

Ошибки доступа, сети и хранилища разобраны в [основной инструкции](../README.md#если-что-то-не-работает). Не отключай TLS и не обходи ограничения организации. Для диагностики передавай только текст ошибки без токена и внутренних материалов.
