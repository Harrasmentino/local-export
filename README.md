# Confluence Local Export

Локальный загрузчик карточек авиакомпаний из Confluence Cloud для сводок и таблиц. Он получает актуальный список карточек и их тексты, а ИИ-агент собирает ответ на твой запрос. Доступы вводятся в отдельном окне Windows и сохраняются на компьютере — передавать токен в чат не нужно. MCP не требуется.

> «Собери в Excel условия добровольного обмена у всех авиакомпаний. Укажи сроки, штрафы, исключения и ссылки на карточки».

Есть и режим без ИИ: готовые Excel и Word по неявке, войдам и штрафам из заданного списка страниц.

## Выбери сценарий

| | Сводка через агента | Фиксированные отчёты без ИИ |
| --- | --- | --- |
| Задача | Произвольная тема, колонки и выборка | Готовые отчёты по заданным темам |
| Источник | Дочерние карточки выбранной базы Confluence | Страницы из файла `links.txt` |
| Новые карточки | Обнаруживаются при каждом запуске | Нужно добавить ссылки вручную |
| Ввод доступов | Отдельная форма Windows | Локальная консоль со скрытым вводом токена |
| Обработка текстов | Материалы читает выбранная модель | Обработка на компьютере, без ИИ |
| Запуск | `CONFLUENCE_AGENT.bat` по инструкции агенту | `VYGRUZKA.bat` |

Ниже — работа с агентом. Для второго сценария есть [инструкция по фиксированным отчётам](docs/FIXED_REPORTS.md).

## 1. Подготовь программу

1. Открой [репозиторий](https://github.com/Harrasmentino/confluence-local-export), выбери **Code → Download ZIP** и распакуй архив. Все файлы должны остаться вместе. Если проект уже скачан, используй его папку.
2. Проверь окружение: **Windows, Python 3.12+ с Tkinter** и доступ к своему Confluence. Для загрузчика агента не нужны Node.js, библиотеки Excel или API-ключ модели.
3. Открой папку проекта в ИИ-приложении, которому разрешено запускать локальные команды и читать файлы. Передай ему [AGENT_GUIDE.md](AGENT_GUIDE.md) и укажи, где находится проект.

**Прикреплённый документ сам по себе не даёт ИИ доступ к компьютеру.** Обычный чат без локальных инструментов не сможет запустить загрузку. Инструкцию можно использовать с разными агентами; в новом чате или другом приложении её может понадобиться передать снова.

### Какой Python используется

Запускной файл `CONFLUENCE_AGENT.bat` рассчитан на Python по адресу:

```text
%USERPROFILE%\.cache\codex-runtimes\codex-primary-runtime\dependencies\python\python.exe
```

Если этот набор библиотек уже есть на компьютере, можно пользоваться `.bat`. Репозиторий не содержит Python, установщика или готового `.exe` и ничего не скачивает автоматически.

С другим установленным Python запускай из папки проекта:

```powershell
python -X utf8 agent_export.py
```

Укажи этот способ запуска агенту. Наличие Tkinter можно проверить командой `python -m tkinter`: должно открыться тестовое окно, которое затем можно закрыть.

## 2. Подготовь ссылку и токен

### Ссылка на базу

Открой нужную **Database** в Confluence, нажми **Ctrl+L → Ctrl+C** и сохрани адрес для формы подключения. Нужен адрес с числом после `/database/`, например:

```text
https://your-company.atlassian.net/wiki/spaces/AIR/database/123456789
```

Это вымышленный пример. Используй свой адрес. Параметры после `?` можно оставить — загрузчик их уберёт. Ссылка на пространство, отдельную статью или короткая `/x/…` для этого поля не подходит. Публичный доступ включать не нужно.

Карточки должны находиться **непосредственно под базой в дереве Confluence**. Сама ссылка на Database не означает, что загрузчик сможет получить все строки и колонки её таблицы; подробнее — в [ограничениях](#полнота-и-свежесть).

### API-токен

1. Войди в [настройки API-токенов Atlassian](https://id.atlassian.com/manage-profile/security/api-tokens) под учётной записью, которой доступны карточки.
2. Выбери **Create API token**, вариант **без scopes**. Только этот тип поддерживает текущая версия загрузчика.
3. Задай название, например `Confluence Local Export`, выбери срок действия и нажми **Create**.
4. Скопируй токен для ввода в локальную форму. Повторно посмотреть его значение нельзя. [Инструкция Atlassian](https://support.atlassian.com/atlassian-account/docs/manage-api-tokens-for-your-atlassian-account/).

Токен без scopes наследует права учётной записи и не ограничен чтением, хотя загрузчик выполняет только чтение. Atlassian рекомендует scopes как более безопасный вариант. Если организация требует их или запрещает такие токены, текущий способ подключения не подходит — не обходи ограничение. [О типах токенов](https://support.atlassian.com/confluence/kb/scoped-api-tokens-in-confluence-cloud/).

**Не отправляй токен в чат, исходный код, команду запуска или файл настроек.**

## 3. Попроси первую таблицу

После передачи инструкции напиши агенту задачу, например:

> Используй AGENT_GUIDE.md. Получи свежие карточки и собери Excel по добровольному обмену у всех АК. Колонки: авиакомпания, условия, сроки, штрафы и доплаты, исключения, ссылка на источник.

Дальше порядок такой:

1. Агент запускает загрузчик. Если среда требует разрешения на локальную команду или сеть, подтвердить его нужно в самом приложении.
2. При первом подключении открывается **отдельное окно Windows**. Вставь туда ссылку на базу, email Atlassian и токен. Нажми **«Подключиться и загрузить»**. Не присылай снимок заполненной формы в чат.
3. Загрузчик получает список доступных дочерних карточек, скачивает все найденные тексты заново и повторно проверяет состав источника. После успешной загрузки доступы сохраняются в хранилище Windows.
4. Агент читает материалы, изучает структуру и собирает таблицу. Если попросить `.xlsx`, файл создаёт агент доступными ему средствами; сам загрузчик готовит исходные данные, а не произвольный Excel.

В ответе должны быть ссылки на источники, время загрузки и количество найденных, обработанных и включённых в выборку карточек. Отсутствующие условия отмечаются как «Не найдено в карточке», противоречия — как «Требует проверки».

Примеры следующих запросов:

- «Обнови данные и сравни условия добровольного возврата у всех АК».
- «Собери условия обмена у иностранных относительно России АК. Укажи страну и основание отбора; неизвестную страну не угадывай».
- «Найди исключения из правил неявки и добавь короткие исходные формулировки».

Если страны или категории нет в карточках, агенту понадобится согласованный справочник либо уточнение. Неизвестные значения должны быть показаны отдельно, а не молча исключены.

## Следующие запуски и замена токена

Продолжай работать в проекте с той же инструкцией и просто задавай новый запрос. Загрузчик каждый раз заново получает список карточек и их содержимое. Ручной `links.txt` в этом режиме не используется.

Пока сохранённые доступы работают, окно подключения не появляется. При **401** программа один раз предложит заменить токен в локальной форме и начнёт загрузку заново. Новый токен заменит сохранённый только после успешной загрузки. При повторном отказе процесс остановится; при **403** автоматической замены нет. Самостоятельно продлевать срок токена программа не умеет.

Для ручного управления выполни нужную команду в PowerShell из папки проекта:

| Действие | Команда |
| --- | --- |
| Получить свежие материалы без запуска анализа | `.\CONFLUENCE_AGENT.bat` |
| Выбрать другую базу и доступы | `.\CONFLUENCE_AGENT.bat --configure` |
| Заменить токен заранее | `.\CONFLUENCE_AGENT.bat --update-credentials` |
| Изменить папку результатов | `.\CONFLUENCE_AGENT.bat --output-dir "D:\PrivateExports"` |

При отдельном Python используй те же параметры после `python -X utf8 agent_export.py`.

## Где находятся результаты

Каждый запуск создаёт отдельную папку внутри:

```text
%LOCALAPPDATA%\ConfluenceLocalExport\agent_exports
```

Вставь этот путь в адресную строку Проводника. Точный путь нового пакета также выводится после сообщения **«Материалы для анализа»**.

| Файл | Содержимое |
| --- | --- |
| `manifest.json` | Статус, время загрузки, количество карточек и ограничения источника |
| `index.json` | Список карточек со ссылками, версиями и названиями разделов |
| `pages/<id>.json` | Полный полученный текст и исходный HTML отдельной карточки |
| `source_snapshot.json` | Общий снимок полученных страниц |
| `source_links.txt` | Список ссылок, обнаруженных именно в этом запуске |

Готовую таблицу агент сохраняет отдельно и сообщает путь к ней. Наличие пакета исходных данных ещё не означает, что таблица создана.

**Если есть `INCOMPLETE.txt` или процесс завершился с ошибкой, пакет нельзя считать готовым.** Агент не должен использовать предыдущую выгрузку под видом свежей.

## Полнота и свежесть

- Источник — доступные учётной записи **страницы с непосредственным родителем Database**, а не все строки, поля и представления Database. Ссылки в её ячейках сами по себе не делают страницу дочерней.
- Вложенные под карточками страницы, вложения и внешние сайты отдельно не обходятся. Динамическое содержимое макросов может отсутствовать в полученном тексте.
- Список берётся через поиск Confluence. Новые карточки попадут в него после индексации, если доступны учётной записи. Скрытые страницы загрузчик не видит.
- Состав проверяется до и после скачивания. Если набор изменился или хотя бы одна карточка не загрузилась, готовый пакет не публикуется.
- Страницы скачиваются последовательно. Это не атомарный снимок, а свежая загрузка на протяжении указанного времени. Она не гарантирует, что авторы своевременно обновили сами правила.
- Таблица ИИ требует проверки перед использованием в работе: правила могут зависеть от тарифа, рынка, GDS и других условий. Ссылки и исходные формулировки помогают сверить выводы.

## Что остаётся локально, а что получает ИИ

Email и токен сохраняются для текущего пользователя в **Windows Credential Manager**: запись `ConfluenceLocalExport:https://<сервер>`. Адрес базы хранится отдельно в `%LOCALAPPDATA%\ConfluenceLocalExport\connection.json`, без email и токена. Загрузчик не включает доступы в пакет и не печатает их в журнал.

**Тексты карточек поступают модели, когда агент читает их для анализа.** Если организация запрещает такую передачу, используй [фиксированные отчёты без ИИ](docs/FIXED_REPORTS.md) и не прикрепляй материалы к чату.

Хранилище Windows не изолирует токен от других программ с правами того же пользователя. Инструкция агенту запрещает читать хранилище и заполненную форму; она не заменяет ограничения доступа приложения. Если хранилище недоступно, открытый файл с токеном вместо него не создаётся.

Для удаления сохранённых доступов открой **Диспетчер учётных данных → Учётные данные Windows → Общие учётные данные** и удали только запись программы для нужного сервера. Это не отзывает токен в Atlassian — отзыв выполняется в настройках аккаунта.

Выгрузки содержат внутренние материалы. Не публикуй их, не добавляй принудительно в Git и выбирай папку хранения согласно правилам организации. `.gitignore` исключает данные и локальные библиотеки, но не управляет OneDrive или резервными копиями.

## Если что-то не работает

| Ситуация | Что проверить |
| --- | --- |
| `Local Python is missing` или нет окна | Наличие Python с Tkinter; путь, который использует `.bat`; доступ процесса к рабочему столу Windows |
| Агент не может запустить программу | Разрешены ли локальные команды и сеть в выбранном приложении. Передача инструкции не создаёт такой доступ |
| **401** | Email, срок и тип токена. Заполни форму замены; токен в чат не отправляй |
| **403** | Права на источник и ограничения организации. Это не обязательно истечение токена |
| **404** | Существует ли карточка и доступна ли той же учётной записи |
| **429** | После ограниченного числа повторов запусти позже |
| Нет карточек или состав изменился | Правильная ли база, есть ли прямые дочерние страницы и права на них; повтори после обновления индекса |
| Ошибка сети или TLS | Подключение, VPN и корпоративные сертификаты. TLS отключать нельзя; системный HTTP-прокси автоматически не используется |
| Ошибка хранилища Windows | Политики компьютера и возможность работы с хранилищем; при запрете обратись к администратору |
| Повреждена настройка источника | Запусти с `--configure` |
| Остался `INCOMPLETE.txt` | Устрани причину и запусти заново. Не используй частичный пакет для итоговой таблицы |

Для диагностики достаточно текста ошибки без токена, внутренних ссылок и содержимого карточек.

## Для разработчиков

`agent_export.py` обходит актуальный список карточек через CQL и собирает пакет; `connection_window.py` показывает форму; `fetch_pages.py` загружает страницы; `windows_credentials.py` работает с хранилищем. Формирование фиксированных отчётов описано [отдельно](docs/FIXED_REPORTS.md#окружение-и-параметры).

Тесты используют вымышленные данные и подменяют сеть и доступы. Они проверяют пагинацию, повтор после 401, отсутствие секретов в результатах, блокировку неполных пакетов и обработку правил. Они не подтверждают доступ к конкретному рабочему Confluence. Для обычной выгрузки запускать тесты не нужно.

```powershell
python -X utf8 -m unittest discover -s tests -v
```
