# Выгрузка без передачи данных ИИ

## Как запустить

После получения кода из Git скопируйте `links.example.txt` в `links.txt` и замените пример своими ссылками Confluence. `links.txt`, выгрузки, логи, локальные библиотеки и QA-результаты намеренно исключены из Git. Не используйте `git add -f` для этих файлов.

1. Откройте **VYGRUZKA.bat** двойным щелчком. Старые `run.bat` и `ZAPUSK.bat` тоже запускают новую версию.
2. При первом запуске введите email и API-токен Confluence **в локальное окно**, не в чат. Ввод токена скрыт. После успешной загрузки всех страниц доступы сохраняются в Windows Credential Manager; следующие запуски используют их без повторного ввода.
3. Дождитесь загрузки всех страниц и сообщения «Сформировано: 2 Excel и 2 Word».
4. Путь к результатам появится в окне. По умолчанию это `%LOCALAPPDATA%\ConfluenceLocalExport\exports\<дата-время>`. Его можно вставить в адресную строку Проводника.

**Каждый запуск заново скачивает все страницы из `links.txt`.** Старый `pages_raw.json` не используется. Если хотя бы одна страница недоступна, отчёты не создаются. Папка неудачного запуска отмечена `INCOMPLETE.txt`. После исправления доступа запускайте ещё раз: будут заново загружены все страницы.

«Свежие» означает содержимое Confluence на момент загрузки каждой страницы. Скрипт не может проверить, своевременно ли авторы обновили саму статью; последовательная выгрузка не является атомарным снимком всего Confluence.

## Когда токен истечёт

При ответе **401** скрипт предложит ввести новые доступы в том же локальном окне. Email можно оставить прежним, нажав Enter; пустой токен отменяет запуск. После ввода все страницы скачиваются заново. Новый токен заменяет сохранённый **только после успешной загрузки всех страниц**. Если новые доступы тоже отклонены, запуск останавливается: бесконечных повторов нет, прежняя запись остаётся без изменений.

**403** означает запрет доступа и не считается доказательством истечения токена. При 403, сетевом сбое или лимите запросов скрипт не требует новый токен автоматически. Проверьте права на страницы и настройки доступа. Если нужно заменить токен вручную, запустите:

```bat
VYGRUZKA.bat --update-credentials
```

Сохранение не продлевает срок действия токена. Истёкший или отозванный токен нужно выпустить заново самостоятельно; скрипт не создаёт токены за вас.

## Что получается

- `aviakompanii_svodka.xlsx`: сводка, войды, штраф при обмене, штраф выше тарифа, неявка, изменения, исходные фрагменты и пояснения.
- `neyavka.xlsx`: неявка, распределение, исходные фрагменты и пояснения.
- `neyavka_tablica.docx`: краткая таблица авиакомпаний и статусов проверки.
- `neyavka_spravochnik.docx`: извлечённые формулировки по неявке и ссылки на источники.
- `source_snapshot.json`: полные свежие страницы, их версии и время загрузки. Содержит конфиденциальные данные.
- `report_data.json`: локальные данные для отчётов. Тоже содержит конфиденциальные данные.
- `report_info.json`: дата сборки и счётчики, без текстов статей и доступов.

Оригиналы от 20.08 не перезаписываются. Файлы нового запуска лежат в отдельной папке, поэтому открытый Excel не мешает следующей выгрузке.

## Отличия от результатов от 20.08

Это детерминированное извлечение, а не ИИ-пересказ. Сохраняются тексты найденных тематических блоков с указанием происхождения; сложные условия не превращаются автоматически в однозначные инструкции.

- Число минут до неявки выводится только из простой явной формулировки целиком в тематическом блоке. Исключения, несколько сроков, косвенные упоминания и неизвестные формулировки отмечаются для ручной проверки.
- «Не найдено» **не означает**, что у авиакомпании нет такого правила.
- Коды такс, способ взыскания штрафа и последствия превышения тарифа не угадываются: показан исходный фрагмент для проверки. Состав колонок поэтому отличается от старых файлов.
- Открытые источники и ФАП автоматически не загружаются и не проверяются; сведения из старых файлов не выдаются за актуальные и не переносятся в новые выводы.
- Короткие листы содержат явно помеченные выдержки. Полный найденный текст — «Исходные фрагменты». Очень длинная ячейка может не поместиться по высоте строки Excel; читайте строку формул, Word-справочник или полный JSON. Тексты длиннее лимита ячейки разбиваются на нумерованные части без потери содержимого.
- Сравнение изменений можно включить параметром `--previous`: старый JSON используется **только для сравнения**, никогда для заполнения свежих отчётов. Без него лист «Что изменилось» сообщает, что сравнение не выполнялось.

## Дополнительные параметры

В командной строке из этой папки:

```bat
VYGRUZKA.bat --previous pages_raw.json
VYGRUZKA.bat --output-dir "D:\PrivateExports"
VYGRUZKA.bat --links "D:\PrivateExports\links.txt"
```

Если сохранённой записи ещё нет, вместо интерактивного ввода можно задать `CONF_EMAIL` и `CONF_TOKEN` в окружении процесса. Сохранённые доступы имеют приоритет над переменными окружения, чтобы устаревшая переменная не возвращала старый токен после замены. `--update-credentials` и повтор после 401 игнорируют сохранённый токен и переменные окружения, запрашивая новые доступы. Не сохраняйте токен в `.bat`, Python-файлах или общих заметках.

Адрес сервера по умолчанию определяется по первой ссылке; `CONF_BASE_URL` позволяет указать ожидаемый HTTPS-сервер. Все ссылки проверяются до чтения хранилища и должны вести на этот же сервер и содержать pageId. Сохранённая запись привязана к серверу; при переходе на другой сервер его доступы запрашиваются отдельно. Перенаправления, HTTP без TLS и сторонние хосты отвергаются.

## Конфиденциальность

- Единственный сетевой этап программы — чтение страниц напрямую из указанного Confluence. В обработке нет ИИ-модели, API ИИ или отправки данных разработчику. Заголовки Authorization не записываются в файлы.
- Email и токен сохраняются средствами Windows в записи `ConfluenceLocalExport:https://<сервер>` в разделе общих учётных данных Диспетчера учётных данных. Используется режим текущего пользователя на этом компьютере, без roaming на другие компьютеры. Это не открытый файл в рабочей папке. Реализация следует [контракту Windows Credential Manager](https://learn.microsoft.com/en-us/windows/win32/api/wincred/ns-wincred-credentialw).
- Хранилище не защищает от программ, уже работающих с правами вашего пользователя. Если Windows запрещает чтение или запись, скрипт сообщает об ошибке и не переходит на сохранение токена открытым текстом. Для забывания доступов можно удалить только запись `ConfluenceLocalExport:https://<сервер>` в Диспетчере учётных данных Windows.
- После скачивания сеть блокируется в Python, а у процесса формирования Excel запрещаются сетевые подключения. Все библиотеки уже находятся на компьютере; автоматической установки из интернета нет.
- Тексты статей, адреса страниц, токены и тела ошибок сервера не печатаются в журнал. Сохраняемые отчёты и JSON при этом содержат исходные данные — не отправляйте их ИИ.
- В прежних `parser.py` / `extract_expands.py` доступы были записаны прямо в коде. Теперь это короткие запускные файлы без доступов. Старые копии, история OneDrive и резервные копии могли сохранить прежние значения. При необходимости отзовите старый токен и выпустите новый.
- Исходная рабочая папка расположена в OneDrive. Скрипт не управляет OneDrive, резервным копированием, DLP, антивирусом или настройками Windows. Новые отчёты по умолчанию складываются в LocalAppData, а не рядом с программой. Проверьте корпоративные требования к хранению данных.

## Зависимости и ошибки

Используются локальные Python 3.12+ с `python-docx`, Node.js и `@oai/artifact-tool` из уже установленного набора Codex. Это библиотеки на диске, не обращение к ИИ. Открытый Codex для обычного запуска не требуется, но его runtime-файлы должны оставаться на компьютере.

По умолчанию runtime: `%USERPROFILE%\.cache\codex-runtimes\codex-primary-runtime\dependencies`. `LOCAL_EXPORT_NODE` и `LOCAL_EXPORT_MODULES` переопределяют пути Node и папки пакетов. `_local\node_modules` — локальная junction-ссылка на папку библиотек. Не копируйте её содержимое в архив программы. Если переносите программу на другой компьютер, пути и библиотеки нужно настроить отдельно.

401: один запрос новых доступов и повторная полная загрузка. 403: проверьте права на страницы, при необходимости используйте `--update-credentials`. 429: скрипт повторяет запрос с ожиданием, но после исчерпания попыток останавливает сборку. Ошибка TLS: проверка сертификата не отключается; проверьте доверенные корпоративные сертификаты. Системный HTTP-прокси автоматически не используется; при обязательном корпоративном прокси нужна отдельная настройка. Никогда не отключайте проверку TLS ради запуска.

`INCOMPLETE.txt` остаётся при любом незавершённом запуске, даже если отдельные файлы уже успели появиться. Используйте только папки без этой отметки.

## Проверка разработчиком

`tests/test_local_export.py` — синтетические тесты извлечения, хранения доступов, повторной авторизации и безопасности. Запуск: `python -X utf8 -m unittest discover -s tests -v` в настроенном локальном runtime.

При разработке дополнительно проверялись сборка настоящих Excel/Word на вымышленных страницах и настоящий Windows Credential Manager на отдельной случайно названной тестовой записи с последующим удалением. Локальные отладочные скрипты и их результаты из `_qa` не включаются в Git. Эти проверки не доказывают доступность вашего Confluence.
